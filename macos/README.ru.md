# Glyphstroke для macOS

Управление устройством жестами мыши: зажать кнопку, нарисовать знак,
отпустить — выполнится назначенное действие. Обычный щелчок при этом работает
как работал.

## Установка

Скачайте `Glyphstroke-0.5.0.dmg`, откройте и перетащите **Glyphstroke** в папку
«Программы». Запустите. При первом запуске программа откроет окно и попросит
два разрешения:

- **Мониторинг ввода** — чтобы видеть движения мыши;
- **Универсальный доступ** — чтобы выполнять действия и знать активное окно.

Кнопки в окне открывают нужную страницу системных настроек. После того как
выдали разрешения, нажмите «Перезапустить» в том же окне.

Значок появится в строке меню — там жесты, настройки, пауза и журнал.

При первом запуске система может показать предупреждение о неизвестном
разработчике: это снимется, когда у программы появится подпись Apple.

## Системные требования

- macOS 13 (Ventura) и новее.
- Apple Silicon (M1 и новее): пакет из релиза собран под arm64. На Intel-маках
  собирается из исходников (см. «Сборка»).
- Дополнительные библиотеки не нужны — программа несёт всё с собой. При первом
  запуске нужно выдать два разрешения: «Мониторинг ввода» и «Универсальный
  доступ».

## Как пользоваться

Зажмите правую кнопку мыши, нарисуйте знак, отпустите. Знаки настраиваются в
редакторе (значок в строке меню → «Жесты…»): можно нарисовать образец или
задать код направлений, например `D-R` — «вниз, потом вправо».

## Возможности

- распознавание росчерков и след за курсором;
- действия: стандартные из списка (копировать, вставить, свернуть окно и
  прочие), клавиши, текст, запуск программ, команды, щелчки, прокрутка, работа
  с окнами;
- редактор жестов с рисованием образцов;
- настройки: кнопка-модификатор, порог росчерка, вид следа, автозапуск;
- проверка обновлений раз в сутки;
- значок в строке меню с паузой и журналом.

## Настройки

Файлы лежат в `~/Library/Application Support/Glyphstroke/`: `settings.yaml` и
папка `gestures/`. Формат общий с версиями для Linux и Windows — набор жестов
переносится копированием папки.

## Сборка

Нужен Xcode или Command Line Tools со Swift 5.9 и новее.

```bash
swift build                  # проверить сборку
swift test                   # тесты ядра
./scripts/build-app.sh       # собрать Glyphstroke.app
./scripts/make-dmg.sh        # собрать образ для раздачи
```

Открыть в Xcode: File → Open → `Package.swift`.

Для раздачи другим нужна подпись и заверение у Apple (учётная запись Apple
Developer): без них образ откроется только на той машине, где собран. Команды
подписи — в комментариях к `scripts/make-dmg.sh`.
