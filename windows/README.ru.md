# Glyphstroke для Windows

Управление устройством жестами мыши: зажать кнопку, нарисовать знак,
отпустить — выполнится назначенное действие. Обычный щелчок при этом работает
как работал.

## Установка

Запустите `Glyphstroke-0.3.5-setup.exe` и пройдите установку. Права
администратора не нужны — программа ставится для одного пользователя.

При первом запуске Windows может показать окно SmartScreen «Windows защитила
ваш компьютер» — так система встречает любую программу без подписи:
«Подробнее» → «Выполнить в любом случае». Это снимется, когда у программы
появится сертификат подписи.

Значок появится в области уведомлений, справа внизу — там жесты, настройки,
пауза и журнал.

## Системные требования

- Windows 10 или 11, 64 бита.
- Дополнительные библиотеки не нужны — установщик самодостаточный, среда .NET
  внутри. Права администратора для установки не требуются.

## Как пользоваться

Зажмите правую кнопку мыши, нарисуйте знак, отпустите. Знаки настраиваются в
редакторе (значок в трее → «Жесты…»): можно нарисовать образец или задать код
направлений, например `D-R` — «вниз, потом вправо».

## Возможности

- распознавание росчерков и след за курсором;
- действия: стандартные из списка (копировать, вставить, свернуть окно и
  прочие), клавиши, текст, запуск программ, команды, щелчки, прокрутка, работа
  с окнами;
- редактор жестов с рисованием образцов;
- настройки: кнопка-модификатор, порог росчерка, вид следа, автозапуск,
  исключённые программы;
- проверка обновлений раз в сутки;
- значок в области уведомлений с паузой и журналом.

## Настройки

Файлы лежат в `%APPDATA%\Glyphstroke\`: `settings.yaml` и папка `gestures\`.
Формат общий с версиями для Linux и macOS — набор жестов переносится
копированием папки.

## Сборка

Нужны [.NET 8 SDK](https://dotnet.microsoft.com/download) и, для установщика,
[Inno Setup 6](https://jrsoftware.org/isdl.php).

```powershell
dotnet build src\Glyphstroke.App          # проверить сборку
dotnet test tests\Glyphstroke.Core.Tests  # тесты ядра
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Последняя команда собирает программу, гоняет тесты и складывает установщик в
`dist`. Без Inno Setup остановится на готовой папке — её уже можно запускать.
Сборка самодостаточная, .NET на машине пользователя не нужен.
