# Glyphstroke

Управление устройством жестами мыши: зажать кнопку, нарисовать знак,
отпустить — выполнится назначенное действие. Обычный щелчок при этом работает
как работал.

Программа есть под три системы. Ядро распознавания у них общее число в число, а
всё, что говорит с системой, у каждой своё — потому и три папки:

| Система | Папка | Как устроен перехват |
|---|---|---|
| Linux (X11 и Wayland) | [`linux/`](linux/) | evdev + uinput, для GNOME на Wayland — расширение оболочки |
| macOS | [`macos/`](macos/) | Quartz Event Services (CGEventTap), Swift + AppKit |
| Windows | [`windows/`](windows/) | низкоуровневый хук, C# + WPF |

Установка и сборка — в README внутри каждой папки.

## Загрузка

Готовые пакеты — на [странице релизов](../../releases/latest): `.deb` для
Linux, `.dmg` для macOS и установщик `.exe` для Windows.

## Системные требования

| Система | Минимум | Дополнительные библиотеки |
|---|---|---|
| Linux | сеанс X11 или Wayland; Python 3.9+ | `python3-evdev`, `python3-yaml` (обязательно); `python3-gi` + `gir1.2-gtk-3.0` для редактора и следа в X11. Пакет `.deb` тянет их сам. |
| macOS | macOS 13 (Ventura) и новее, Apple Silicon | не нужны — программа несёт всё с собой |
| Windows | Windows 10 или 11, 64 бита | не нужны — установщик самодостаточный (.NET внутри) |

Подробности по каждой системе — в README её папки.

## Жесты переносятся между системами

Формат файлов общий: `settings.yaml` и `gestures/*.yaml`. Набор жестов
переносится с машины на машину копированием папки. Чтобы переносились и
действия, у жестов есть тип «стандартное действие» — в файле лежит имя
(`copy`, `back`, `minimize`), а нужное сочетание клавиш подставляет та система,
где жест выполняется: `ctrl+c` на Linux и Windows, `cmd+c` на маке.

## Как это работает

Пока зажата кнопка-модификатор (по умолчанию правая), её нажатие
придерживается. Отпустили без росчерка — программа досылает обычный щелчок, и
контекстное меню открывается как всегда. Провели росчерк — щелчок не досылается,
выполняется привязанное действие. Форма росчерка сверяется двумя способами:
кодом направлений (`D-R` — «вниз, потом вправо») и по нарисованным образцам
(алгоритм $1 Unistroke).

## Обновления

Каждая версия раз в сутки проверяет, не вышел ли выпуск новее, и, если вышел,
показывает об этом сообщение со ссылкой. Сама программа не обновляется:
перехват мыши — не то место, где уместна тихая подмена, ставит новую версию
человек. Проверку можно выключить в настройках.
